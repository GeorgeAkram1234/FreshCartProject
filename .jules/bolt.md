## 2024-06-29 - Shared Query Client and Request Deduplication
**Learning:** Instantiating the `QueryClient` inside a component function (like `App.jsx`) causes it to be re-initialized on every re-render, effectively clearing the cache. Moving it to the module level ensures cache persistence across the entire application lifecycle. Additionally, "N+1" network bottlenecks in list views can be cleanly resolved by shifting from individual `useEffect` fetches to a shared React Query key, enabling automatic request deduplication and significantly reducing server load.
**Action:** Always define the `QueryClient` outside of the component tree. When implementing data fetching in components that appear multiple times (like list items), use shared query keys and appropriate `staleTime` to prevent redundant network traffic.
