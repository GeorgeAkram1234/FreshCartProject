## 2025-05-14 - Optimized wishlist data fetching and implemented code splitting
**Learning:** React Query's default behavior of request deduplication is a powerful tool for solving N+1 API call problems in component-based architectures. By sharing a query key across multiple component instances, we can ensure only one network request is made even if hundreds of components need the data simultaneously. Additionally, static imports in wrapper components like `ProtectedRoute` can block the effectiveness of route-based code splitting.
**Action:** Always prefer `useQuery` for data needed by multiple components. When implementing code splitting, ensure that any "gatekeeper" components (like `ProtectedRoute`) use navigation/redirects instead of static imports of the guarded components to allow proper chunking.
