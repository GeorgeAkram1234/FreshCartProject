## 2025-05-15 - [Strict Focus on Single Optimization]
**Learning:** Combining multiple performance optimizations (e.g., route-based code splitting and image lazy loading) or including functional changes (e.g., routing logic updates) in a single PR can lead to rejection. Additionally, ensuring build artifacts like 'dist/' are excluded from the repository is critical for a clean submission.
**Action:** Focus on ONE measurable optimization at a time and strictly verify that no build artifacts are being tracked by Git.
